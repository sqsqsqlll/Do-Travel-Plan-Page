怎么导入 / 导出？

📥 导入：把自己的行程放进来

  1. 打开 旅游AA账本，在「预算」「地点」里记下这趟旅行的日期、车票、门票、住宿和想去的地方；
  2. 点页面上方行程条里的「⚙ 管理」，在对应行程上点「🗺 行程页」，下载 trip-data.json；
  3. 回到这里点「📥 导入行程」，选择这个文件，页面会立刻换成你的行程。

导入的行程只保存在当前这台设备的这个浏览器里；换手机、换浏览器或清除网站数据后需要重新导入。点「↺ 清除导入」可回到默认内容。

📤 导出：备份、分享或发布

  1. 点「📤 导出当前行程」，下载正在显示的行程 trip-data.json（导入的、示例的都可以导出）；
  2. 发给同行的人：对方打开本网站，用「📥 导入行程」选择这个文件即可看到同样的行程；
  3. 让所有人打开网址就能看到：用它替换 GitHub 仓库 Do-Travel-Plan-Page 根目录的 trip-data.json（或发给 Claude 代为替换）；
  4. 导回账本：在旅游AA账本「⚙ 管理 → 📥 从行程页导入」选择这个文件，航班、住宿、门票、费用会变成预算项，景点和餐厅进入地点库。

待办勾选、门票「已购票」状态和本页记账也都只存在当前浏览器，不会随文件导出。行程文件里如有订单号、地址等信息，公开发布前请先确认。
